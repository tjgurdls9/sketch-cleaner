# Sketch Cleaner 구현 계획

## 0.2.0 자동 초안 스프린트

확정 여정은 사진 선택 → 자동 정리 → 사용자 직접 수정 → 확인 및 저장이다. `IMPLEMENTATION_SPEC.md` 상단 변경 기준을 따른다. 추가 요금·모델 설치·외부 호출 없이 기존 파일 형식과 복구 경계를 재사용한다.

- S0 메인: 6개 인수 조건, 버전/설치 설정과 파일 계약 고정.
- S1 Luna xhigh engine: 제한된 분석 크기의 자동 정리 엔진, 저확신 무변경, 보호/범위/입력 불변식 및 성능 측정.
- S1 Luna xhigh ui: 새 사진의 자동 실행, 직접 수정·저장 중심 화면, 취소/undo/버전 경합 검사.
- S2 Luna xhigh storage/QA: 독립 합성 작업지, 실제 설치 앱 자동→수정→저장·재개 E2E, 보안/저장 비용 점검.
- S3 메인: 담당별 기준 대조·보완, 타입/린트/테스트/보안/Windows CI, 비공개 PR과 사용자용 ZIP. 실제 업무 사진 품질과 사용자 PC 성능은 미검증으로 분리.

기준: `IMPLEMENTATION_SPEC.md` 전체. Windows 11 x64 / Electron + TypeScript + Canvas 2D + Forge. 일반 사용자는 설치 파일과 클릭만 사용한다. AI 호출·로그인·업로드를 앱에 구현하지 않는다.

공유 작업 폴더에서는 파일 소유권을 분리한다. 에이전트는 타 담당 파일과 package.json/공통 타입을 수정하지 않으며 커밋·원격 쓰기는 메인만 수행한다. 병렬 단계의 분리 브랜치는 파일 소유권과 메인의 단계별 커밋으로 대체해 병합 충돌을 피한다. 작업 결과는 `docs/handoff-<담당>.md`에 남긴다.

## 사용자 여정과 범위

1. JPEG/PNG 열기·드롭 → 방향 보정된 기준 → 자르기/회전/기울기. 기존 마스크 초기화는 확인·취소 및 undo 가능.
2. 빨강 삭제, 파랑 보호, 표시 해제, 기준 복원, 올가미 안/밖. 확대/이동과 무관한 이미지 좌표. 브러시 크기·강도·부드러움.
3. 선택 영역 채우기/색 추출/밝기/대비 미리보기 → 명시 적용. P=255는 B 그대로, A=0은 직전 W 그대로. 세션 undo/redo.
4. 로컬 자동 저장·명시 저장·다른 폴더 저장·최근 열기·복구 안내. 원본 사본, 원본 파일 쓰기 금지. 새 리비전 완성 후 포인터 교체.
5. 요청별 input/guide/request 및 당시 버전·마스크·기준 보관. 외부 처리 안내. 고정 ChatGPT URL과 폴더만 열기.
6. 번호 선택 → 후보 가져오기 → 나란히/겹침/마스크 표시 → 이동/배율/회전 정렬 → 확인 후 부분 적용. 기준 버전이 다르면 비교만, 요청 버전에서 새 작업 지원.
7. 최종 PNG 미리보기·원본 크기·실제 경로 표시. 덮어쓰기 대신 새 파일 기본. 인터넷 없이 로컬 편집·저장.

## 검증·보안과 복구

- 엔진과 저장 경계의 테스트를 먼저 만들고 실제 누락으로 실패한 RED 결과를 남긴 후 구현한다. 메인은 RED/GREEN을 구분해 커밋한다. 전체 커버리지 목표 80%, 미달은 명시한다.
- 저장 경계는 50MB/25MP, 포맷 실제 디코딩, 모든 크기·배열·마스크·버전·경로·심볼릭 링크, 디스크 오류, 임의 IPC 입력을 검증한다.
- 로컬 번들 + 엄격 CSP + sandbox + contextIsolation, Node renderer 비활성화. sender 검증, navigation/window deny, 네트워크 요청 금지. URL은 고정 `https://chatgpt.com/`만 main에서 연다. 이미지나 경로 원격 로그 없음.
- 각 담당 보고는 테스트 → 스펙 대조 → 보안 → UI 순서로 검토한다. 미달은 구체적 실패 사례로 되돌리고 보완 확인 후 완료 처리한다.
- 독립 실패 복구: 실패 리비전은 포인터를 바꾸지 않는다. 손상 현재 리비전은 검증된 이전 리비전으로 복구 표시한다. 입력 원본은 수정하지 않는다.
- Git 단계 커밋으로 롤백. 사용자 프로젝트를 개발 롤백으로 삭제하지 않는다.

## 실기기 의존 인수

실제 Plus 계정·업무 사진이 제공되지 않아 선행 품질 검증은 보류 상태다. 로컬 기능과 선택적 수동 전달 흐름은 구현하되 GPT 품질을 보장하지 않는다. Windows 설치/업데이트/제거, DPI 100/150/200%, 실사진 10장·업무 시간 3장, 20MP 성능, 계정 한도/실패, 강제 종료·용량 부족의 실제 Windows 시험은 자동 테스트 결과와 별도로 기록한다. 서명·실무 인수 전에는 테스트 빌드다.

## 상태

- 계획: 독립 검토 완료. 기준/작업 이미지 분리, 후보 역변환과 유효 픽셀, 이력 버전 계약 보완.
- 엔진: 구현·검토 완료. 보호/범위 불변식, 구간별 브러시, Worker 취소·결과 버퍼 전송, 제한된 세션 이력.
- 저장: 구현·검토 완료. 보호 픽셀 검증, 리비전 재읽기 검증, 복구된 포인터 보존, 다른 폴더 직접 저장, 부속 파일 손상 격리.
- 화면: 구현·검토 완료. 한국어 도구/요청/검수/저장, 비동기 전환 보호, 작은 화면 핵심 조작 유지.
- 통합: 타입·린트·자동 테스트 51개·빌드 통과. 개발 호스트 패키징 통과. 상세는 `docs/ACCEPTANCE.md`와 `docs/TDD_EVIDENCE.md`.
- Windows CI: Server 2025 x64에서 51개 테스트·타입·린트·설치 파일 생성·실제 설치된 앱의 부분 선택/보호/정렬/적용/PNG E2E 통과. 설치·같은 버전 재설치·제거 시 기본 데이터 폴더 보존 검사도 통과.
- Windows 11 실기기 인수: 미실행. 비개발자 설치·GUI·DPI·20MP 성능·업무 사진·Plus 품질은 검증 대기.
- 원격 저장소: `https://github.com/tjgurdls9/sketch-cleaner` 비공개·쓰기 권한 확인, 7개 단계 커밋 업로드 및 각 파일 트리 해시 일치 확인 완료. GitHub 연결 도구로 재생한 이력과 로컬 원래 이력의 대응은 `docs/GIT_PROTOCOL.md`에 기록. 후속 보완은 PR #5로 검증. 원본이나 결과 사진은 업로드하지 않음.
