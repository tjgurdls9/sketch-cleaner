# Main-process storage and security handoff

The main process now exposes the shared `DesktopAPI` through a narrow preload bridge. Renderer calls carry project and request IDs only; file paths are selected by Electron dialogs or resolved from the main process's project registry. IPC replies use `{ ok, value }` or a sanitized Korean error. The exact ChatGPT URL is opened in the system browser, and the app only copies request text to the clipboard.

Imports require a JPEG or PNG extension, matching file signature and decoded format, one page, at most 50 MB and 25 million pixels. Sharp applies EXIF orientation before editor pixels are returned. Projects keep the selected source bytes unchanged and record their SHA-256 hash. Internal lossless PNGs use a separate 126 MB bound, sized for the maximum supported RGBA raster and PNG row overhead. The source path is metadata only; export rejects its original path, symlink aliases, hard links, and the managed source copy. PNG exports use exclusive creation and select a numbered filename when the chosen name already exists.

The Squirrel installer identity is `SketchCleanerDesktop`, while managed projects remain under `%LOCALAPPDATA%\SketchCleaner\projects`. The separate install root keeps Squirrel uninstall cleanup away from project data.

Each saved state is a new immutable revision containing the working image, base image, both masks, and version/dimension metadata. The files are decoded and compared to the submitted snapshot before the project pointer is replaced atomically. Fully protected pixels (`protectMask = 255`) must retain the exact RGBA bytes from the base image. A failed replacement leaves the existing pointer intact. Opening validates schemas, image dimensions, masks, content hashes, request files, candidate files, and project-contained paths; symlinks in project references are rejected. Invalid current pointers recover from a verified previous pointer or an older valid revision and return `recovered: true`. Corrupt request or candidate files mark the project recovered while leaving a valid working snapshot openable; those files remain available for diagnosis and their load calls reject them. Saving after recovery preserves a normalized verified pointer rather than copying corrupt primary bytes over it.

Request folders contain `input.png`, `guide.png`, `request.txt`, metadata, and an immutable base/working/mask snapshot. `createRequest` returns the exact `RequestBundle` from the shared contract and rejects guide dimensions that differ from the saved snapshot. `forkRequest` creates a fresh project from that snapshot, records source provenance, rewrites the copied request's project ID, and copies candidates linked to it. `saveProjectAs` clones the current snapshot, all requests, and linked candidates to a fresh project ID directly in the selected destination; it does not write to the default projects root. The selected copy is registered for the current session, while a later session can open its chosen folder through the project picker. `openFolder` opens the managed project root or a selected request folder.

The BrowserWindow uses `sandbox`, `contextIsolation`, and `webSecurity`, with Node integration disabled. IPC validates the sender webContents, main frame, and exact local renderer entry URL. Navigation, redirects, popups, permission requests/checks, and renderer HTTP(S)/WebSocket/FTP requests are denied. The initial window dimensions and minimum size clamp to the primary display work area. The renderer build is local and the app has no upload or remote logging path.
