# 의류 도해 정리 · 한 장 안내

전달받은 테스트 빌드 ZIP의 압축을 풀고 `SketchCleaner-0.3.0-Setup.exe`를 실행하세요. 설치 후 시작 메뉴의 **Sketch Cleaner**로 엽니다. Node·Python·명령어·API 키는 필요하지 않습니다. 테스트 설치 파일은 서명되지 않아 Windows 경고가 표시될 수 있습니다.

**사진 선택 → 원본 확인 → 자동 정리 → 직접 수정 → 확인·저장** 순서로 사용합니다. ChatGPT 단계는 필요할 때만 사용합니다.

## 1. 원본을 확인하고 자동 정리를 누르세요

앱에서 **사진 열기**를 누르거나 JPEG·PNG 사진 한 장을 작업대로 끌어 놓으세요. PDF·HEIC는 지원하지 않습니다. 앱 입력 상한은 50MB·2,500만 픽셀입니다.

새 사진은 원본 모습으로 열립니다. **자동 정리**를 누르면 앱에 포함된 AI가 PC 안에서 글씨 범위를 찾고, 확실한 주변 표시를 정리합니다. 인터넷 연결·모델 설치·API 키·추가 결제는 필요하지 않습니다. 분석과 적용 중에는 취소할 수 있으며, 실패하거나 취소하면 사진과 편집 내용을 유지합니다. 성공한 자동 정리는 실행 취소 한 번으로 되돌립니다.

도해선과 글씨가 겹치거나 판단이 어려운 영역은 남길 수 있습니다. 모든 글씨·필기·도해 양식을 정확히 구분하는 기능은 아니므로 결과를 확인하고 다음 단계에서 보정하세요.

필요하면 자르기, 90도 회전, 기울기 조절부터 하세요. 영역을 칠한 뒤 기준을 바꾸면 삭제·보호 표시가 초기화된다는 안내가 나옵니다. 취소하거나 실행 취소할 수 있습니다. 원본 파일은 바뀌지 않습니다.

## 2. 자동 결과를 직접 수정하세요

자동 결과를 100%에서 살펴보세요. 남은 글씨는 삭제 표시로 칠하고 **칠한 곳 지우기**를 누릅니다. 사라진 도해 선은 **기준 복원**으로 원본에서 되살립니다. 아래 도구로 필요한 부분만 보정할 수 있습니다.

- **삭제 표시 / 빨강:** 바꿔도 되는 곳입니다. 강도를 낮추면 기존 이미지가 일부 남습니다.
- **보호 표시 / 파랑:** 남길 선과 부분입니다. 삭제 표시와 겹치면 보호가 우선하며 작업 기준으로 돌아갑니다.
- **표시 지우기:** 사진을 지우지 않고 삭제·보호 표시만 지웁니다.
- **기준 복원:** 해당 부분을 작업 기준 이미지로 돌립니다.
- **올가미 선택:** 둘러싼 안쪽 또는 바깥쪽을 선택합니다.

크기·강도·경계 부드러움을 조절할 수 있습니다. 휠로 확대하고 스페이스바를 누른 채 드래그하면 화면을 이동합니다. **100%**에서 도해 선을 확인하세요.

## 3. 선택한 곳만 정리하세요

선택한 곳을 흰색이나 사진에서 찍은 배경색으로 채우세요. 종이색과 그림자는 밝기·대비를 미리 본 뒤 **적용**하세요. 보호 영역과 선택하지 않은 부분은 유지됩니다. 전체 사진을 바꾸려면 먼저 전체를 명시적으로 선택해야 합니다.

글씨와 도해 선이 겹친 부분은 정확히 자동 복원되지 않습니다. 실행 취소·다시 실행과 기준 복원으로 수정하세요. 로컬 편집만으로 충분하면 바로 저장할 수 있습니다.

## 4. 필요할 때만 ChatGPT에 수동 요청하세요

**요청 → 요청 파일 만들기 → 파일 위치 열기** 순서로 진행하세요. `input.png`를 첫 번째로, `guide.png`를 두 번째로 ChatGPT에 첨부하고 **문구 복사**로 복사한 요청을 붙여 넣으세요. **ChatGPT 열기**는 공식 웹사이트를 기본 브라우저로 엽니다.

**직접 첨부한 사진은 외부에서 처리됩니다.** 외부 처리 금지인 회사 자료는 첨부하지 말고 로컬 편집만 사용하세요. 앱이 사진을 자동 전송하지는 않습니다. 모델·사용 한도·완료 여부는 ChatGPT 계정 화면을 따릅니다. 한도에 도달하면 프로젝트를 저장해 두고 나중에 이어서 작업하세요. 별도 API 결제로 전환되지 않습니다.

웹에서 첨부가 거부되면 그 오류 안내를 먼저 확인하세요. 앱은 이미지 크기를 자동으로 바꾸지 않습니다. 작은 이미지가 필요하면 현재 프로젝트를 보존하고 별도 사본에서 필요한 부분을 자른 뒤 새 요청을 만드세요.

## 5. 결과를 비교하고 선택한 곳에만 적용하세요

ChatGPT 결과를 PC에 다운로드한 뒤 **검수**에서 해당 요청 번호를 선택하고 가져오세요. 나란히 보기·겹쳐 보기를 사용해 윤곽·주름·봉제선·점선이 보존됐는지 확인하세요. 같은 해상도라도 선이 맞는다는 뜻은 아닙니다.

후보만 이동·배율·회전해 맞추고, 확인란을 선택한 다음 **선택 영역에 적용**하세요. 정렬할 수 없는 결과는 적용하지 말고 다시 요청하거나 로컬 편집으로 마무리하세요. 요청 후 자르기·회전으로 기준이 달라졌으면 직접 적용이 차단되며 요청 당시 기준으로 새 작업을 만들 수 있습니다.

## 6. 저장하고 다음에 이어서 작업하세요

프로젝트는 편집 후 자동 저장되며 **프로젝트 저장**으로 직접 저장할 수도 있습니다. 기본 위치는 `%LOCALAPPDATA%\SketchCleaner\projects`입니다. 저장 오류가 보이면 **저장 다시 시도** 또는 **다른 폴더에 저장**을 사용하세요. 오류가 남아 있으면 저장 완료로 간주하지 마세요.

**저장 → PNG 저장**에서 최종 파일 위치를 선택하세요. 저장 완료 후 실제 경로와 픽셀 크기를 확인하세요. 원본과 같은 경로에는 저장할 수 없고, 기존 파일과 이름이 겹치면 새 이름으로 보존합니다. 삭제·보호 색 표시는 PNG에 들어가지 않습니다.

다음에는 시작 화면의 **최근 작업**이나 **프로젝트 열기**로 이어서 작업합니다. 비정상 종료 후 복구된 작업은 별도로 표시됩니다. 실행 취소 이력은 앱을 종료하면 사라집니다. 프로젝트 폴더는 앱 제거 전후에도 직접 보관하세요. OneDrive·운영체제 백업 설정과 브라우저 다운로드 위치는 앱이 통제하지 않습니다.

저장된 프로젝트를 다시 열 때는 자동 정리를 반복하지 않으므로 직접 수정한 결과가 유지됩니다.
